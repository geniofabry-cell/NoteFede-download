# NoteFede

Note, attività, promemoria e idee in un posto solo. App gratuita per **Windows 10 e 11 (64 bit)**.

**[Scarica l'ultima versione](https://github.com/geniofabry-cell/NoteFede-download/releases/latest)** · [Sito](https://notefede.date/) · [Privacy](https://notefede.date/privacy.html) · [Termini](https://notefede.date/termini.html)

- `NoteFede-Setup-x.y.z.exe`: installer (consigliato), con collegamenti sul desktop e nel menu Start.
- `NoteFede-x.y.z-portable.exe`: si avvia senza installazione.

Al primo avvio Windows può mostrare "Windows ha protetto il PC": clicca **Ulteriori informazioni → Esegui comunque** (l'app non ha una firma digitale a pagamento). Poi entra con il tuo account **Google** o **Discord**: serve solo a riconoscerti, le note restano sul tuo computer.

Problemi o domande? Apri una [segnalazione](https://github.com/geniofabry-cell/NoteFede-download/issues).
